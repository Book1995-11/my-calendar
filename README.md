# My Calendar

ปฏิทินส่วนตัวสำหรับจัดการงานและวางแผนงาน ทำงานบนเบราว์เซอร์ล้วน (HTML/CSS/JS) ไม่ต้องมี server และเปิดใช้ผ่าน GitHub Pages ได้

**เปิดใช้งาน:** https://book1995-11.github.io/my-calendar/

## ฟีเจอร์

- ปฏิทินมุมมองเดือน / สัปดาห์ / วัน / รายการ
- เพิ่ม แก้ไข ลบงาน, ลากวางเพื่อเปลี่ยนวัน, ลากขอบเพื่อปรับระยะเวลา
- งานแบบทั้งวันหรือระบุเวลา, ความสำคัญ (สี), สถานะ (ยังไม่เริ่ม / กำลังทำ / เสร็จแล้ว)
- ซ่อนงานที่เสร็จแล้ว
- **แผนงาน**: จัดกลุ่มงานเป็นแผน กำหนดสีของแต่ละแผน และกรองทุกมุมมองตามแผน
- **บอร์ด Kanban**: ยังไม่เริ่ม / กำลังทำ / เสร็จแล้ว ลากการ์ดเพื่อเปลี่ยนสถานะได้
- **Gantt**: timeline ของงาน แสดงตามสีแผน ลากเพื่อเลื่อนวัน ปรับระยะเวลา และ % ความคืบหน้าได้
- สถานะกับความคืบหน้าเชื่อมกัน (เสร็จแล้ว = 100%)
- **สีของงาน**: เลือกสีให้แต่ละงานได้ (ถ้าไม่เลือก ใช้สีแผนงาน หรือสีตามความสำคัญ)
- **วันหยุด / วันพิเศษ**: วันหยุดบริษัท วันลา กิจกรรม แบบวันเดียวหรือหลายวัน ซ้ำทุกปีได้ พร้อมปุ่มเพิ่มวันหยุดราชการไทยที่วันที่ตายตัว
- **วันหยุดประจำสัปดาห์**: เลือกได้ (เช่น หยุดเฉพาะวันอาทิตย์) แสดงแรเงาในปฏิทินและ Gantt
- นับ **จำนวนวันทำงาน** ของงาน และเตือนเมื่อช่วงงานทับวันหยุด
- งานที่ **เลยกำหนด** แสดงเป็นสีแดงบนบอร์ด
- **งานซ้ำ**: ทุกวัน / ทุกสัปดาห์ (เลือกวันได้) / ทุกเดือน / ทุกปี, ทุกๆ N ครั้ง, กำหนดวันสิ้นสุด, ข้ามวันหยุดได้ และติ๊ก "เสร็จ" แยกแต่ละครั้ง
- **Checklist** ในงาน: % ความคืบหน้าคำนวณจาก checklist อัตโนมัติ
- **ลำดับงาน (dependencies)**: กำหนดว่างานไหนต้องรองานไหนเสร็จก่อน แสดงเป็นลูกศรใน Gantt และเตือนเมื่อเริ่มก่อนงานที่ต้องรอจะเสร็จ
- **ชี้เมาส์ดูรายละเอียด**: ชี้ที่งานในทุกมุมมองเพื่อดูช่วงวันที่ สถานะ รายละเอียด checklist และงานที่ต้องรอ โดยไม่ต้องคลิกเปิด
- **ค้นหา** งานจากชื่อ รายละเอียด และ checklist
- แท็บ **สรุป**: งานเลยกำหนด, วันนี้, 7 วันข้างหน้า, กำลังทำ, ความคืบหน้าตามแผน, วันหยุดที่จะมาถึง
- **สำรอง / นำเข้าข้อมูล** (.json) แบบรวมหรือแทนที่ พร้อมแถบเตือนเมื่อไม่ได้สำรองเกิน 14 วัน
- **ส่งออก .ics** ไปใช้กับ Google Calendar / Outlook (รวมงานซ้ำและวันหยุด)
- **พิมพ์ / บันทึกเป็น PDF** มุมมองที่เปิดอยู่ (A4 แนวนอน)
- รองรับมือถือและ Dark mode

## ข้อมูลเก็บที่ไหน

ข้อมูลทั้งหมดเก็บใน **localStorage ของเบราว์เซอร์แต่ละเครื่อง** ไม่มีการส่งขึ้น server หรือ GitHub
ดังนั้นแต่ละเครื่องหรือแต่ละเบราว์เซอร์จะมีข้อมูลแยกกัน และถ้าล้างข้อมูลเว็บไซต์ งานจะหายไปด้วย

ใช้เมนู **เพิ่มเติม → สำรอง / นำเข้าข้อมูล** เพื่อดาวน์โหลดไฟล์สำรองเป็นระยะ และใช้ไฟล์นั้นย้ายข้อมูลไปเครื่องอื่น

## วิธีใช้งานในเครื่อง

**Windows:** ดับเบิลคลิก `start.bat` (ต้องมี Python 3) จะเปิด server ที่ http://localhost:8000/ และเปิดเบราว์เซอร์ให้อัตโนมัติ กด `Ctrl+C` ในหน้าต่างเพื่อหยุด

หรือรันเอง:

```bash
python -m http.server 8000
```

> ข้อมูลผูกกับที่อยู่เว็บ: `localhost:8000`, การเปิดไฟล์ `index.html` ตรงๆ และ GitHub Pages จะมีข้อมูลแยกกันคนละชุด

## Deploy ด้วย GitHub Pages

1. Push โค้ดขึ้น GitHub repo (public)
2. ไปที่ **Settings → Pages**
3. Source: **Deploy from a branch** → Branch `main`, Folder `/ (root)`
4. รอสักครู่ แล้วเปิด `https://<username>.github.io/<repo>/`

## โครงสร้างโปรเจค

```
index.html        หน้าหลัก
css/style.css     ธีมและ layout
assets/icon.svg   ไอคอน
js/dateutil.js    ตัวช่วยจัดการวันที่ (เวลาท้องถิ่น)
js/format.js      สี ป้ายกำกับ และการแสดงช่วงวันที่
js/ui.js          ตัวช่วยหน้าต่าง (dialog) และค่าที่จำไว้ในเบราว์เซอร์
js/specialdays.js วันหยุด/วันพิเศษ และการนับวันทำงาน
js/tasks.js       กฎของงาน: สถานะ/ความคืบหน้า, เลยกำหนด, ค้นหา, ลำดับงาน
js/recurrence.js  งานซ้ำ: คำนวณวันที่แต่ละครั้ง
js/storage.js     อ่าน/เขียนข้อมูลใน localStorage และนำเข้า/ส่งออก
js/backup.js      ไฟล์สำรอง .json และไฟล์ปฏิทิน .ics
js/tooltip.js     กล่องรายละเอียดเมื่อชี้เมาส์ที่งาน
js/calendar.js    มุมมองปฏิทิน (FullCalendar)
js/board.js       มุมมองบอร์ด Kanban
js/gantt.js       มุมมอง Gantt (Frappe Gantt)
js/summary.js     มุมมองสรุป
js/taskdialog.js  หน้าต่างเพิ่ม/แก้ไขงาน
js/app.js         หน้าต่างแผนงาน/วันหยุด/สำรองข้อมูล และการเชื่อมต่อทุกส่วน
```
